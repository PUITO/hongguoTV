# hongguoTV

手机统一管理 + 电视播放

## v0.4 播放方式与手机统一设置

### 两种播放方式（手机切换，电视跟随）

| 模式 | 说明 |
|------|------|
| **推流** | 手机缓存后，电视播 `http://手机:8765/stream/current`（更稳、利于防盗链） |
| **直链** | 电视直接播源站 URL（省手机流量与电量） |

### 扫码绑定后

手机端可管理全部设置，减少在电视上操作：

- 播放方式（推流 / 直链）
- 自动连播、默认倍速
- 电视控制条显示、保持亮屏
- 是否允许电视本机按键
- 片源推送、换集、暂停、倍速

电视只负责显示与播放，设置以手机轮询下发为准。
