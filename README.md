# hongguoTV

手机解析推流 + 电视极简播放（局域网 companion）。

## v0.2

- **扫码绑定**：电视显示二维码，手机扫码完成绑定（也可手动 IP+配对码）
- **手机遥控**：播放/暂停、倍速（0.75–2.0）、自动连播、下一集
- 电视轮询手机控制状态并跟随

## 使用

1. 手机与电视同一 WiFi  
2. 电视打开「红果电视」，看到二维码  
3. 手机打开「红果推流」→ 启动服务 → **扫电视二维码绑定**  
4. 手机推送播放地址，并用底部按钮控制倍速/连播  

## 构建

```bash
./gradlew :phone:assembleDebug :tv:assembleDebug
```

GitHub Actions 自动构建 APK。
