# hongguoTV

手机解析推流 + 电视播放（局域网 companion）

## v0.3

1. **接入红果网页源**：手机搜索 / 系列ID+集数解析播放地址  
2. **缓存推流**：手机边下边缓存，电视播 `http://手机:8765/stream/current`，支持 Range，预取下一集  
3. **电视播放器**：本地换集 / 倍速 / 播放暂停；遥控器左右换集、中键暂停；状态与手机同步  

## 使用

1. 同一 WiFi，电视开 App 显示二维码  
2. 手机启动服务 → 扫电视码绑定  
3. 搜索剧名或填系列ID+集数 → 解析并推送  
4. 电视自动播放；手机或电视均可换集、调倍速  

## 构建

```bash
./gradlew :phone:assembleDebug :tv:assembleDebug
```
